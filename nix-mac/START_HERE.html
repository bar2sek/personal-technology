🖥️ Mac AI Workstation — Unboxing & Quick Start Guide

M5 Pro 48GB Ready for zero-fiddle Day 1 deployment.

1 Physical Preparation (Before Booting)

  • Wash hands thoroughly with degreasing soap.
  • Clean keycaps with a microfiber cloth lightly misted with 70% Isopropyl Alcohol.
  • Dab keycaps with painter's tape to lift any micro-dust.
  • Apply Barekey decals with curved fine-point tweezers.
  • Allow 12–24hr contact time before vigorous rubbing.

2 Initial macOS Setup Assistant

  • Turn on your new Mac and follow the Apple Setup Assistant.
  • Enable FileVault disk encryption when prompted.
  • Sign into your Apple ID (for iMessage, FaceTime, and Keychain).
  • ⚠️ CRITICAL: When Apple asks "Store files from Desktop and Documents in iCloud Drive?" → UNCHECK THE BOX.

3 1-Click Bootstrap Installation

Plug in this USB drive, open the default Terminal app on your Mac, and run:

bash /Volumes/*/templates/bootstrap.sh

(If you copied this folder to your Downloads folder instead, run: bash ~/Downloads/Mac\ AI\ Workstation/templates/bootstrap.sh)

What this single script does automatically:

  • Installs Xcode CLI Tools, Homebrew, and Determinate Nix.
  • Installs Visual Studio Code, Ghostty, Google Drive, Obsidian, OrbStack, and AppCleaner.
  • Installs JetBrainsMono Nerd Font system-wide.
  • Auto-configures Ghostty (matching fonts, ligatures, Tokyo Night theme).
  • Arranges your Dock in your exact 3-section layout (Browsers → Apple Core → Dev Tools).
  • Disables browser telemetry on Edge/Brave and sets Google as default search.
  • Purges GarageBand and iMovie bloatware to reclaim 5–8 GB of SSD space.

4 Setting Up Your AI Provider Keys

This workstation runs no local models — all inference is remote, so the only setup needed is credentials.

Create API keys for the providers you use (Anthropic, Google AI Studio, xAI), then add them to ~/.zshrc so they persist:

export ANTHROPIC_API_KEY="..."
export GEMINI_API_KEY="..."
export XAI_API_KEY="..."

Reload your shell with source ~/.zshrc, then copy the Continue config and substitute your real key:

cp client-tools/ai-dev/continue-config.json ~/.continue/config.json

Open Visual Studio Code and use Continue.dev (Cmd + L for chat, Cmd + I for inline edits). Antigravity IDE uses Gemini natively, with Claude and Grok available through the Roo Code switcher.

⚠ Never commit an API key. Treat every repository here as public — a leaked key is compromised the moment it lands, and rotating it is the only fix.
